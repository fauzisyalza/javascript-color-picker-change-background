# 🎨 JavaScript Color Picker - Change Background

Simple Color Picker app to change the page background color by clicking on color circles.

### ✨ Features
- 4 color choices: Red, Blue, Green, Black
- Background changes instantly when a circle is clicked
- Title text color adjusts automatically for readability
- Reset button to restore default white background
- Built with `querySelectorAll`, `addEventListener`, and `getComputedStyle`

### 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla JS)

### 🚀 How to Use
1. Click one of the color circles (Red / Blue / Green / Black)
2. The page background will change to that color
3. Click `RESET` to return the background to white
